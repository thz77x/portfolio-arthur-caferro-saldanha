# Pixel Realm – Especial NieR: Automata

## Descrição do Projeto

O **Pixel Realm** é um site de 5 páginas dedicado ao universo de **NieR: Automata**, com conteúdo sobre a história do jogo, personagens, guias e um formulário de contato. O objetivo foi praticar a estrutura de um site multipágina com HTML5 e o posicionamento de elementos com CSS.

Desenvolvido para a disciplina de **Desenvolvimento Front-End Para Web (2026.2)**.

As páginas são: Home, Sobre, Personagens & Lore, Análises & Guias e Contato.

## Tecnologias Utilizadas

- HTML5 e CSS3
- VS Code

## Resultados e Aprendizados

- Criação de cinco páginas interligadas por um menu de navegação.
- Organização do conteúdo com tags semânticas e estilos centralizados em `css/style.css`.
- Inclusão de imagens e formulário de contato.
- **Aprendizados:** praticar a estruturação semântica do HTML, a aplicação de estilos com CSS e a organização de arquivos de um site multipágina.
