# Deploy do Site Pixel Realm

## Descrição do Projeto

Esta atividade consistiu na publicação online do site Pixel Realm, desenvolvido na AT1, utilizando o GitHub Pages. O objetivo foi disponibilizar o site por meio de um endereço público.

Desenvolvido para a disciplina de **Desenvolvimento Front-End Para Web (2026.2)**.

## Tecnologias Utilizadas

- HTML5 e CSS3 (site desenvolvido na AT1)
- Git, GitHub e VS Code
- GitHub Pages

## Resultados e Aprendizados

- Publicação do site da AT1 em um endereço acessível pela web.
- **Aprendizados:** compreender o processo de publicação pelo GitHub Pages, organizar os arquivos do projeto no repositório e verificar o funcionamento das páginas e imagens após o deploy.
