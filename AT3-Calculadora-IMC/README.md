# Calculadora de IMC

## Descrição do Projeto

Calculadora de Índice de Massa Corporal (IMC) em uma única página. O usuário informa peso em quilogramas e altura em metros; o JavaScript calcula o IMC pela fórmula peso ÷ altura² e apresenta o resultado com duas casas decimais e uma classificação geral para adultos. A página também valida os valores informados e apresenta um aviso sobre a interpretação do IMC para menores de 18 anos.

Desenvolvido para a disciplina de **Desenvolvimento Front-End Para Web (2026.2)**.

## Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
- GitHub e GitHub Pages

## Resultados e Aprendizados

- Formulário com campos de peso e altura.
- Cálculo e exibição do resultado sem recarregar a página.
- Validação dos valores e classificação por condicionais.
- **Aprendizados:** utilizar eventos de formulário, `preventDefault()`, capturar valores dos campos, validar entradas e apresentar resultados dinamicamente com JavaScript.
