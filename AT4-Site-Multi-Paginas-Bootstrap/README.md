# PixelRealm 2

## Descrição do Projeto

O **PixelRealm 2** é um site responsivo de cinco páginas, com navegação entre Início, Sobre, Galeria, Dados e Contato. O projeto tem como objetivo praticar a construção de um site multipáginas, com navegação consistente, layout responsivo e componentes do Bootstrap, dentro da disciplina de **Desenvolvimento Front-End Para Web (2026.2)**.

## Tecnologias Utilizadas

- HTML5 e CSS3
- Bootstrap 5
- VS Code, Git e GitHub
- GitHub Pages

## Resultados e Aprendizados

- Desenvolvimento de cinco páginas interligadas.
- Utilização de componentes e recursos do Bootstrap, incluindo grid responsivo, cards, modais, tabela, accordion e formulário.
- Complementação dos estilos com CSS próprio.
- **Aprendizados:** aplicar o sistema de grid do Bootstrap, reutilizar componentes e manter os arquivos de um site multipáginas organizados.

## Declaração de Uso Ético da IA

Foram utilizadas as ferramentas **Claude (Anthropic)** e **ChatGPT (GPT)** como apoio durante o desenvolvimento, principalmente na depuração de problemas e na produção de conteúdo textual e visual. O código HTML e CSS foi desenvolvido pelo estudante, que revisou e testou o resultado. O uso das ferramentas serviu como apoio, sem substituir a participação do estudante no desenvolvimento e na validação do projeto.
